# India-specific factor data gap

The application has a small India-oriented lookup library and a licensed UK/ADEME public catalogue. Neither is a validated, representative India-specific lifecycle inventory database. Illustrative averages remain marked as such; proxy suitability requires review of unit, geography, technology, date and boundary.

We have not established that no free India-specific data exists. The open issue is obtaining sufficiently relevant, validated data with clear redistribution rights and traceable boundaries for this application's intended users. CEA electricity factors, supplier measurements, public studies and other Indian sources are possible leads, not automatically interchangeable full LCI datasets or permission to redistribute.

Before adding a source, record its publisher, original table/record, factor value and unit, region, measurement/reference year, lifecycle boundary, gas/GWP basis, uncertainty and licence. Missing values remain unknown. Use source-specific evidence and distinguish update date from measurement year. Do not scrape paid libraries or use noncommercial-only data in a commercial product. Review rights at dataset level, not from a software's open-source label.

User-facing claims should say "licensed public activity factors with manual applicability review", not "verified India LCI" or "automatic exact matching". Vendor assurance is a separate workflow, not a database label or internal approval checkbox.
